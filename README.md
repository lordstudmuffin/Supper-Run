# Supper Run

A co-op cooking roguelike for two, played on your phones.

Each round you draw a theme, ingredient cards and a modifier, cook together as head chef and sous chef, rate the dish, and file it in the Recipe Book or the Hall of Legendary Failures.

## Install

Open the app link on your phone, then add it to the home screen:

- **iPhone:** open in Safari, tap Share, then "Add to Home Screen".
- **Android:** open in Chrome, tap the menu, then "Add to Home screen" or "Install app".

## Sharing one kitchen

In the app, open "How saving and sharing works". One phone starts a shared kitchen and sends its link code to the other phone, which pastes it in. Both phones then show the same round, ratings and Recipe Book.

## Files

The app is the files at the top of this repository. `src/` holds the source; `sh src/build.sh` rebuilds the page from it.
